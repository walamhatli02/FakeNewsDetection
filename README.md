# 🔍 Fake News Detection – Python for Data Science 2

> **Complete ML project:** EDA → Preprocessing → Modeling → API → Frontend → Docker

---

## 📋 Project Overview

This project builds an end-to-end **Fake News Detection** system using the ISOT Fake News Dataset. It covers the full ML lifecycle from raw data to a deployed web application.

| Week | Topic | Deliverable |
|------|-------|-------------|
| 1 | Setup, EDA | `notebooks/week1_eda.ipynb` |
| 2 | Preprocessing & Feature Engineering | `notebooks/week2_preprocessing.ipynb` |
| 3 | Modeling (Boosting) + MLflow | `notebooks/week3_modeling_mlflow.ipynb` |
| 4 | API Development (FastAPI) | `api/main.py` |
| 5 | Frontend (React) | `frontend/src/App.jsx` |
| 6 | Containerization (Docker) | `docker-compose.yml` |

---

## 🗃️ Dataset

**ISOT Fake News Dataset** (Kaggle)

- Download: https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset
- Place `True.csv` and `Fake.csv` inside the `data/` folder
- ~44,000 articles (21,000 real + 23,000 fake)

## 🚀 Quick Start

### 1. Clone & Install
```bash
git clone <your-repo>
cd fake_news_project
pip install -r requirements.txt
```

### 2. Download the dataset
Place `True.csv` and `Fake.csv` in the `data/` folder.

### 3. Run the notebooks in order
```bash
jupyter notebook
# Run: week1_eda.ipynb → week2_preprocessing.ipynb → week3_modeling_mlflow.ipynb
```

### 4. Start the API
```bash
uvicorn api.main:app --reload --port 8000
# Docs: http://localhost:8000/docs
```

### 5. Start the React frontend
```bash
cd frontend
npm install
npm start
# App: http://localhost:3000
```

### 6. Run everything with Docker
```bash
docker-compose up --build
# API:      http://localhost:8000
# Frontend: http://localhost:3000
# MLflow:   http://localhost:5000
```

## 🤖 ML Pipeline

### Feature Engineering
- **TF-IDF** (50,000 features, 1-2 ngrams, sublinear TF)
- **Handcrafted features:**
  - Number of `!` and `?` (sensationalism)
  - Uppercase ratio (shouting style)
  - Average word length
  - Article length (words)
  - Unique word ratio (vocabulary richness)
  - Subject category (encoded)

### Models Compared

| Model | Accuracy | ROC-AUC |
|-------|----------|---------|
| Logistic Regression | ~98% | ~0.998 |
| XGBoost | ~99% | ~0.999 |
| **LightGBM** ✅ | **~99%** | **~0.999** |

### MLflow Experiment Tracking
- Start server: `mlflow ui --port 5000`
- View at: http://localhost:5000
- Tracks: all hyperparameters, metrics, and model artifacts

## 🔌 API Reference

### `POST /predict`
```json
{
  "title": "Federal Reserve raises interest rates",
  "text": "The Federal Reserve announced...",
  "subject": "politics"
}
```

**Response:**
```json
{
  "label": "REAL",
  "label_id": 1,
  "confidence": 0.9874,
  "fake_probability": 0.0126,
  "real_probability": 0.9874
}
```

### `GET /health` – API health check
### `GET /docs` – Interactive Swagger UI
### `POST /predict/batch` – Predict up to 50 articles at once
